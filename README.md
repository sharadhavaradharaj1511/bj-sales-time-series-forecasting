# BJ Sales Time Series Forecasting

## Project Type
Academic Team Project | Baylor University

## Project Overview
Performed time series analysis and forecasting on BJ Sales data using R and the fpp3 framework to identify trends, stationarity, autocorrelation, and predictive relationships.

## Tools & Skills Used
- R Programming
- fpp3
- Time Series Analysis
- Forecasting
- ACF/PACF Analysis
- Regression Modeling
- ARIMA Concepts
- Data Visualization

## Key Work Performed
- Converted sales data into tsibble format
- Identified trends and stationarity in time series data
- Applied differencing to remove trends
- Conducted autocorrelation analysis using ACF plots
- Built regression models and evaluated residual patterns
- Compared forecasting suitability using regression and ARIMA concepts

## My Contribution
Collaborated on time series analysis, trend removal, ACF interpretation, regression modeling, and forecasting evaluation using R.
